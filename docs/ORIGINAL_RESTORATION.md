# 원본 한글 파일 복원

2026-10-11, 사용자가 재배포 허락을 확인하고 학생 사진이 있는 자료를 제외한 원본 한글 파일의 공개를 요청했습니다. 기존 공개용 PDF 206개를 원본 파일·텍스트·삽입 이미지 검토 기록과 대조했습니다.

| 처리 | 수량 |
| --- | ---: |
| 원본 HWP로 복원 | 125 |
| 학생 사진이 있어 공개용 PDF 유지 | 45 |
| 특정 학생의 장애·건강·가정 배경이 드러나 공개용 PDF 유지 | 25 |
| 원본 자체가 PDF인 자료 | 11 |
| 전체 공개 지도안 | 1,928 |

복원한 자료는 한려초 71개와 기존 교육지원청 자료 54개입니다. 사진과 함께 분류했던 학생 활동 화면·텍스트 이미지를 재검토하여 실제 학생 사진과 구분했습니다. 특수학급 등의 개별 학생 민감 정보는 저작물 재배포 허락과 별도로 공개용 PDF를 유지합니다.

원본은 변환하거나 본문을 편집하지 않았습니다. 수집 당시의 SHA-256·파일 크기와 HWP 파일 서명을 대조하고, 기존 학년·교과·단원·출처를 유지하여 ZIP 제출·관리자 승인 절차로 반영했습니다. 교내 운영계획·보조자료 제외 기준은 유지합니다. 교체 전 공개 파일·기록과 검토 내역은 Git에서 제외한 로컬 staging에 보관합니다.

검증은 카탈로그 무결성, 원본 다운로드의 파일명·확장자·크기·SHA-256과 구분하여 수행합니다. 한컴오피스에서의 문서 열기·페이지 렌더링은 이 검증에 포함되지 않습니다. 실제 배포 여부는 GitHub Actions 완료와 배포 주소의 파일 응답을 따로 확인합니다.

로컬 검증 결과: 전체 1,928개 자료의 승인 상태·경로·크기·SHA-256 및 중복 검사가 통과했습니다. 빌드·타입 검사, 앱 테스트 40개와 관리자 테스트 10개가 통과했습니다. 복원한 HWP 125개를 HTTP로 다운로드하여 원본 해시와 HWP FileHeader·BodyText 구조를 확인했고, 브라우저 다운로드 9개 표본의 원래 파일명·확장자·내용을 대조했습니다. 학년 7개 구분과 단원 필터, 1440·1024·768·390·320px 화면을 확인했습니다. 유지한 PDF 81개의 무결성과 비공개 원본·교체된 PDF가 빌드 출력에 없는 것도 확인했습니다.
