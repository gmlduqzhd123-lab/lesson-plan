# 자료실 입장 화면

서재 초대형 1안을 적용합니다. 공개 지도안 수는 승인·중복 검증을 통과한 catalog/index.json과 연동하며, 로딩 및 목록 오류를 실제 개수와 구분합니다.

입장 순서: 유의 사항 탭 → 전문을 끝까지 스크롤 → 이용 약속 동의 → 확인 버튼 → 비밀번호 → 자료실 입장. 스크롤과 동의는 확인 절차이며 실제 독서를 증명하지 않습니다. 모든 앱 경로와 직접 연결한 상세 화면에도 같은 화면 입장 절차를 적용합니다.

비밀번호 원문은 소스·배포 파일에 저장하지 않고 소금값을 포함한 SHA-256 검증값만 저장합니다. 성공 후 해당 탭의 sessionStorage에 버전별 입장 확인값을 저장하며 입력한 비밀번호는 지웁니다. 저장이 차단된 환경에서는 현재 화면에서만 입장을 유지합니다. 유의 사항 또는 비밀번호 변경 시 확인 버전을 갱신해야 합니다.

## 보호 범위

GitHub Pages에서 동작하는 클라이언트 화면 제한입니다. 서버 인증이 아니므로 개발자 도구로 우회할 수 있으며, 공개 저장소·카탈로그·지도안 원본의 직접 URL 접근은 차단하지 않습니다. 해시 또한 클라이언트에 제공되므로 강력한 비밀 보호로 취급하지 않습니다. 파일까지 비공개로 제공하려면 인증된 서버나 별도 비공개 저장소가 필요합니다.
