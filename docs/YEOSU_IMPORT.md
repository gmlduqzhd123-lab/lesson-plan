# 여수교육지원청 자료 등록

2026-10-11 수집·원문 대조·사용자 허락 확인 후 등록했습니다.

- 출처: https://ysed.jge.go.kr/ysed/na/ntt/selectNttList.do?mi=10648&bbsId=10648
- 범위: **게시 등록일** 2024-01-01 ~ 2026-12-31. 수업 예정일과 제목의 연도는 범위 판단에 사용하지 않았습니다.
- 대상: 16개 게시물, 17개 첨부. 2026년 2개·2025년 14개·2024년 0개.
- 2024년 확인: 게시번호 8002(2025-04-14) 다음은 8001(2023-11-15)이며 제목 `2024` 검색도 결과가 없었습니다. 이 2024~2026년 작업의 범위에는 2023년 이전 자료가 포함되지 않았습니다. 이후 추가 요청한 자료는 [2022·2023년 등록 기록](YEOSU_2022_2023_IMPORT.md)에 정리했습니다.
- 16개 HWP 본문을 오프라인으로 추출하고 단원·대상 학년·교과를 대조했습니다. 이미지 PDF 1개는 텍스트가 없는 스캔으로, 전체 5쪽을 시각 검토했습니다. 이 추출 작업은 공개 앱의 HWP 자동 분석 지원 확대를 의미하지 않습니다.
- 유치원 자료 3개는 초등 학년 대신 유아·유아교육, 생활·놀이 주제로 분류했습니다. 영재교육원 자료는 성취기준의 학년군 대신 실제 수업 대상 5학년으로 분류했습니다.
- 동일 수업의 HWP와 스캔 PDF는 서로 다른 파일이며 두 형식을 모두 등록했습니다. 기존 목록과 SHA-256이 같은 파일은 없었습니다.
- 사용자는 이번 여수 자료의 재배포 허락도 받았다고 확인했습니다. 별도 CC/공공누리 허락으로 표시하지 않았습니다.
- 민감 학생 설명이 있는 국어 자료 1개는 사용자 승인에 따라 해당 문단과 특정 학급·인원별 수준 정보를 삭제한 공개용 PDF로 대체했습니다. 원본 HWP와 비공개 검토 기록은 Git에서 제외한 `staging/`에 보관합니다.
- HWP 내부 이미지 46개와 스캔 PDF 전체 5쪽을 검토했습니다. 공개용 PDF는 전체 5쪽의 렌더링과 민감 문자열 삭제를 확인했습니다.
- 제출 ZIP 17개 항목 → 비공개 가져오기 → 개인정보·저작권 검토 승인 → 정적 목록 생성 순서로 반영했습니다.

이 작업의 새 자료는 HWP 15개·PDF 2개이며 당시 공개 목록은 총 63개입니다. 각 항목에 출처 URL, 원본 파일명, 형식, 파일 크기, SHA-256, 분류 메모를 보존합니다. 공개용 정리본은 원본의 표·그림 배치를 재현하지 않았다고 상세 화면에 명시합니다.
