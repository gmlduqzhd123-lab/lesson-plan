# 여수교육지원청 2022·2023년 자료 등록

2026-10-11 수집·원문 대조·개인정보 검토 후 공개 가능한 자료를 등록했습니다.

- 출처: https://ysed.jge.go.kr/ysed/na/ntt/selectNttList.do?mi=10648&bbsId=10648
- 범위는 제목·수업 예정일이 아닌 **게시물 등록일 2022-01-01~2023-12-31**입니다. 29개 목록 페이지를 확인해 2021년 경계까지 대조했습니다.
- 대상 게시물 1,424개: 2022년 1,233개, 2023년 191개. 첨부 참조 1,777개를 내려받아 SHA-256 중복을 정리한 고유 파일은 1,728개입니다.
- 새 공개 자료 **1,721개**: 2022년 게시 자료 1,505개, 2023년 게시 자료 216개. 하나의 게시물에 여러 첨부가 있어 게시물 수와 파일 수가 다릅니다.
- 공개 형식은 HWP 1,499개, HWPX 12개, PDF 210개입니다. 같은 수업의 서로 다른 파일·형식은 보존하고 바이트가 같은 첨부는 하나만 등록했습니다.
- 새 자료 중 유아 자료 207개는 유아교육·놀이 주제로 분류하고, 학교 운영 계획·활동지·서식은 수업 보조자료 92개로 구분했습니다. 초등 자료의 실제 학년을 확인하지 못한 22개는 추정하지 않았습니다.
- HWP/HWPX 본문과 PDF 텍스트를 오프라인으로 추출했습니다. 이미지 PDF 58개, 323쪽은 한국어 OCR과 렌더링으로 검토했습니다. HWP/HWPX 내부 이미지 770개도 검토했습니다. 이는 공개 앱의 HWP 자동 분석 기능을 확대한 것이 아닙니다.
- 사용자는 이번 2022·2023년 자료까지 재배포 허락을 확인했습니다. 원저작자의 별도 CC·공공누리 허락으로 표시하지 않았습니다.
- 사용자 지시에 따라 민감한 학생 설명·학생 식별 정보·학생 사진이 있는 **120개**는 재질문 없이 삭제한 공개용 PDF로 대체했습니다. 전체 공개용 PDF를 렌더링하고 접촉 시트로 배치를 확인했으며, 대표 페이지는 원래 크기로 확인했습니다. 삭제된 원본과 검토 기록은 Git에서 제외한 비공개 `staging/`에 보관합니다.
- 공개용 PDF는 추출한 텍스트를 재배치한 정리본이며 원문의 표·그림 배치를 재현하지 않습니다. 이미지 PDF에서 변환한 자료에는 OCR 글자 차이 가능성도 표시합니다. 공개 카탈로그에 본문 미리보기는 넣지 않았습니다.
- 58개 제출 ZIP을 비공개 가져오기 → 검토 승인 → 공개 폴더 반영 순서로 처리했습니다. 제출과 공개 승인은 기존 관리자 절차로 분리합니다.

## 공개하지 않은 자료

암호화된 HWP 2개와 본문이 비어 있는 HWP 1개는 내용 검토가 불가능하여 비공개로 보관합니다. 보조 슬라이드 PPT/PPTM/PPTX 4개는 현재 지원 형식이 아니므로 비공개로 보관합니다. 첨부가 없는 게시물 7개는 실제 지도안 파일을 만들거나 등록하지 않았습니다.

첨부 없는 게시번호: 1863818, 1841602, 1812605, 1808108, 1807733, 1804582, 1790539.
검토 불가 HWP 게시번호: 1813183, 1792401, 1809593.

## 앱 변경과 검증 범위

약 29MiB인 실제 HWP가 있어 파일당 제한을 32MiB로 조정했습니다. 총 100MiB·최대 30개·압축 해제 160MiB 제한과 서명·해시·경로 검증은 유지합니다. 검색은 전체 카탈로그를 대상으로 수행하고 카드 표시는 60개씩 늘립니다. 필터 변경 시 표시 수는 60개로 초기화합니다.

로컬 테스트와 실제 배포 검증은 별도 결과로 보고합니다. 브라우저 화면 폭 검증은 실물 PC·태블릿·휴대폰 시험을 의미하지 않습니다. 비공개 원본은 공개 Git 저장소나 Pages 배포 산출물에 포함하지 않습니다.
