# 파일 분석·제출 호환성 수정 (2026-10-12)

`crypto.randomUUID`가 없는 브라우저 조건에서 파일 선택 후 분석 행이 만들어지지 않고 콘솔에만 오류가 나타나는 문제를 재현했습니다. 제출 ZIP 식별자 생성도 같은 기능에 의존했습니다.

두 경로에 공통 UUID 생성기를 적용했습니다. 해당 API가 없으면 Web Crypto의 `getRandomValues`로 UUID v4를 생성하며, 초기 처리가 불가능한 경우 화면에 오류를 표시합니다. 오류 후에도 파일 선택을 다시 시도할 수 있습니다.

검증: 단위·화면 테스트 49개, 관리자 테스트 10개, 전체 승인 자료 1,928개의 경로·크기·SHA-256 검증과 프로덕션 빌드를 통과했습니다. 브라우저에서 기본 조건과 `randomUUID` 없는 조건 모두 파일 선택 → 실제 HWP/PDF 및 합성 HWPX 분석 → 개별 수정 → 손상·중복 파일 제외 → ZIP 다운로드 → 관리자 패키지 검증과 원본 바이트 일치를 확인했습니다. 기존 공개 원본을 시험하기 위해 해당 시험 브라우저에서만 목록을 빈 배열로 가로챘으며, 공개 목록에는 시험 자료를 추가하지 않았습니다. 320·390·768·1280px 화면에서 가로 넘침이 없었습니다. 실제 구형 기기 검증은 포함하지 않습니다.

파일은 기기에서 처리하고 관리자 제출용 ZIP을 생성합니다. 자동 서버 업로드나 공개 등록은 하지 않으며 관리자 검토·승인 과정은 별도입니다.
